# Freight Rate Prediction — Machine Learning Assessment

## Overview

This repository contains my solution for Spotter's Machine Learning Engineer freight-rate prediction assessment. The objective is to predict a posted freight rate for each load from lane, shipment, market, quote, and calendar information.

The development set contains 48,000 labelled loads. I used a chronological validation split rather than a random split so the local evaluation better represents the production setting: predicting future loads from historical data.

## Validation strategy

- Development period: July–October 2025.
- Training split: July–September 2025.
- Holdout split: October 2025.
- Final model: retrained on the full labelled development data after model selection.
- Local holdout results: MAE $136.01, RMSE $172.97, MAPE 7.15%, R² 0.820.

A time-based split was selected to reduce optimistic validation caused by randomly mixing earlier and later market conditions.

## Features

The pipeline parses the shipment date and derives calendar features such as month, day of week, day of month, week of year, and ordinal day. It also creates operational features including rate-per-mile signals, weight/distance interaction, lane, and route/equipment combinations. Missing categorical and numeric values are handled explicitly.

## Model

The final estimator is CatBoostRegressor. It was selected because this is structured tabular regression with a mix of numeric and categorical variables, including relatively high-cardinality location/lane fields. CatBoost can model nonlinear interactions and categorical variables without a large one-hot encoded matrix.

## Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Place the assessment files `train-test.csv`, `validation.csv`, and `validation-predictions-template.csv` in `data/`, then run:

```bash
python src/train_predict.py
```

Validate the required outputs and create the December chart:

```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

The provided scorer validates the submission format and writes `scorer_results/candidate_december.png`. Spotter calculates final validation metrics after submission.

## Reproducibility

The model uses a fixed random seed. Package requirements are pinned in `requirements.txt`.

## Submission outputs

- `validation_predictions.csv`: predictions for all 12,000 validation loads.
- `data/december_chart_inputs.csv`: completed 31-day fixed-input December predictions.
- `scorer_results/candidate_december.png`: chart generated by the supplied scorer.
